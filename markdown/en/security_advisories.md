# nginx security advisories

**Revision:** 1  
**Language:** en

All nginx security issues should be reported to [F5SIRT@f5.com](mailto:F5SIRT@f5.com) or via one of the methods listed [here](https://github.com/nginx/nginx/blob/master/SECURITY.md) .

Patches are signed using one of the [PGP public keys](pgp_keys.xml) .
