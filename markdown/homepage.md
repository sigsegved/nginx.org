# nginx

**Revision:** 2  
**Language:** en

nginx (" *engine x* ") is an HTTP web server, reverse proxy, content cache, load balancer, TCP/UDP proxy server, and mail proxy server. Originally written by [Igor Sysoev](http://sysoev.ru/en/) and distributed under the [2-clause BSD License](../LICENSE) .
